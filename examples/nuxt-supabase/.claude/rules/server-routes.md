# Серверные routes (acme)

- Вход валидируется по схеме до любой работы с данными — сырое `body` в запрос не уходит.
- `service_role`-клиент — только здесь и только за проверкой авторизации: анонимный вызов
  привилегированного route недопустим. Исключения (вебхуки с проверенной подписью)
  фиксируются в `memory/decisions.md`.
- Presign для приватного bucket: TTL ≤ 10 мин, ключ привязан к `workspace_id`, MIME-whitelist
  и лимит размера обязательны; confirm-шаг берёт размер из метаданных Storage, а не из тела
  запроса, и пишет строку клиентом под RLS.
- Сессии и токены — в httpOnly cookies, `secure` управляется env (в prod — `true`).
- Секреты не попадают в ответ, логи и сообщения об ошибках; `.env.example` актуален.
